# Mint Petroleum Ltd - Official Website

Official single-page website for **Mint Petroleum Ltd**, powering progress consistently across Zambia and Southern Africa.

## Features
- **Modern Responsive Design**: Faithfully recreated from the company profile presentation into semantic HTML5, CSS3, and modern typography.
- **High-Performance Assets**: Responsive WebP images with fallbacks.
- **Direct Engagement**: Sticky header with direct Call, WhatsApp, and Email actions.
- **Comprehensive Company Profile**:
  - Managing Director's Message
  - Who We Are & Strategic Direction (Vision, Mission, Core Purpose)
  - Core Values ("The Mint Way")
  - Energy Solutions & Integrated Services
  - Industries Served (Mining, Agriculture, Transport, Construction, Manufacturing, Power)
  - Health, Safety, Security & Environment (HSSE) Standards
  - Statutory Compliance & Verified Registrations (PACRA, Tax Clearance, ZPPA, TPIN)
  - Official PDF Profile Download

## Development & Local Preview
Open `index.html` in any web browser, or run a local static web server:
```bash
python3 -m http.server 8000
```
